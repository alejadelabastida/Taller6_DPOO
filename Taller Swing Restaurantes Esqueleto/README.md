# Taller 6 – GUIs con Swing y Java2D

## Cómo ejecutar
**Eclipse:** 
Clic derecho sobre `VentanaPrincipal.java` > Run As > Java Application.

## Cómo usar la aplicación
1. **Ventana principal:** muestra la lista de restaurantes. Al seleccionar uno se ven abajo su nombre, su calificación (estrellas) y si fue visitado.
2. **Nuevo:** abre la ventana para agregar un restaurante. Se escribe el nombre, se elige la calificación (1 a 5) y si fue visitado, y se hace clic sobre el mapa para marcar su ubicación (aparece un punto rojo). Con *Crear restaurante* se agrega a la lista; con *Cerrar* se cancela. El nombre es obligatorio.
3. **Ver todos:** abre la ventana del mapa, donde se dibujan con Java2D el punto y el nombre de cada restaurante. Los radio buttons permiten ver Todos o solo los Visitados
